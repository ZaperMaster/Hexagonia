# Seguridad

## Informar de una vulnerabilidad

Si encuentras un fallo de seguridad en Hexagonia (por ejemplo, en la conexión multijugador):

1. **No abras una issue pública.**
2. Usa la opción privada de GitHub: pestaña **Security → Report a vulnerability** de este repositorio.
3. Incluye los pasos para reproducirlo y el impacto que crees que tiene.

Intentaré responder en un plazo de 7 días y avisarte cuando esté corregido.

## Protección del repositorio

Este repositorio tiene activados el análisis de código (CodeQL), los avisos de dependencias (Dependabot) y la
detección de secretos.
